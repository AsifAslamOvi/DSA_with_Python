# 📚 DSA with Python

A complete **Data Structures & Algorithms** course implemented in Python —
covering everything from Python basics to recursion, with hands-on Jupyter Notebooks.

---

## ⚠️ GitHub Notebook Rendering Issue

GitHub sometimes fails to render `.ipynb` (Jupyter Notebook) files and shows:

> **"An error occurred"**

This is a known GitHub limitation with the `nbformat` and `nbconvert` rendering engine.
To solve this problem and make the content always accessible, a **dedicated website** was
built that fetches all files live from this repository and lets you view every notebook
in a clean, readable format via **nbviewer**.

## 🗂️ How to Use the Website

Follow these steps to browse and read any notebook clearly:

**Step 1 — Open the website**
Click the link above to open the DSA course website.

**Step 2 — Select a topic**
Browse the modules listed on the page (e.g. `1-Python Basics`, `3-Data Structure`, etc.)
and click on any `.ipynb` file you want to read.

**Step 3 — Click "nbviewer" for best format**
A modal will open showing the file content.
In the top-right of the modal, click the **📓 nbviewer** button.
This opens the notebook in [nbviewer.org](https://nbviewer.org) — the cleanest,
most readable format for Jupyter Notebooks, with proper code highlighting and output.
